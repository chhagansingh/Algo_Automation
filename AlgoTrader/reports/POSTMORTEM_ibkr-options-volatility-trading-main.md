## 2. What This Project Actually Is

This is a **notification bot**, not an automated trading strategy. Here's the entire logic:

```python
# 1. Read YAML file with ~100 stocks pre-classified:
#    - "long straddle" stocks = historically volatile (GME, AMC, etc.)
#    - "short straddle" stocks = historically stable (JNJ, KO, IBM, etc.)

# 2. Every 5 seconds, fetch daily % change from Yahoo Finance

# 3. For each stock:
#    - If classified as "long straddle" and |daily_change| > LONG_THRESHOLD (e.g., 2%):
#      → ALERT: "Buy straddle, big move expected"
#    - If classified as "short straddle" and |daily_change| < SHORT_THRESHOLD (e.g., 0.5%):
#      → ALERT: "Sell straddle, no move expected"

# 4. Send email + Slack with the alerts
# 5. Trader manually decides which ones to actually trade
```

That's it. No backtest. No P&L tracking. No automated execution. No risk management.
